# QA Test Design Portfolio

A manual QA portfolio for a fictional smart-city platform with web/mobile clients, real-time incident updates, payment flows and CRM functions.

The artifacts are intentionally structured like a small production QA pack:

- risk-based test strategy;
- test cases in CSV;
- decision table for payments;
- state-transition model for incidents;
- exploratory testing charter;
- simulated bug reports with technical evidence expectations.

All defects and product behavior in this repository are **fictional training scenarios**.

## Suggested review order

1. `docs/test-strategy.md`
2. `docs/decision-table-payments.md`
3. `docs/state-transition-incidents.md`
4. `test-cases/`
5. `bug-reports/`

## Skills demonstrated

Test design, prioritization, regression thinking, real-time behavior, mobile/web differences, payments, CRM, permissions and troubleshooting-oriented bug reporting.
